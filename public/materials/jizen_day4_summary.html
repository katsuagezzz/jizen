Day5 講義のまとめ

サプライチェーンとバイヤーの力・AIで「立ち位置」を数字にする

🔗
📖 Day5の資料「自分の身をどこに置くか？ - ミクロ編」を開く

🎯 今日の持ち帰り

  1. 「やりたいこと」から職種を決める前に、国 → 業種 → 会社 → 部署の順に、お金が多く流れているところを探す。夢とお金は分けて考えてもいい
  2. サプライチェーンで見ると、どの会社も売る側（セラー）と買う側（バイヤー）の顔を持つ。自由市場では、一般にバイヤーの方が強い
  3. 同じ会社でも、仕入れ（購買）の部署は売り込まれる側、営業は断られる側。部署によって立場とストレスが違う
  4. AI講座：業界×サプライチェーンの工程で年収・売上・利益を比べられる。どう調べるか（How）より、何を調べるか（What）が大事
🛂

おさらい：個人では破れない「制度の壁」

ビザ思いだけでは働けない

  • アメリカで働きたくても、就労ビザがなければ働けない
  • 国が外国人の就労を規制するのは、自国民の仕事が減る＝選挙に直結するから
  • 制度は個人ではなかなか変えられない。仕組みを知った上で、個人の自由を追求する

スターターまずはワーホリ

  • 特別な証明がなくても海外で働ける、若者のための特例
  • 海外で見たビジネスを日本に持ち込む「タイムマシン経営」は、起業家の定番のアイデア
🔍

国 → 業種 → 会社 → 部署とブレイクダウン

  • 「やりたいこと」はどんどん変わる狭い見聞でやりたいことを決め、ガクチカと履歴書を作って職種にマッチングする（ジョブ型）——その前に、大きいところから考える
  • 同じ仕事でも、業種で給料が違う同じエンジニアでも、自動車・金融・アパレルで給料は違う。日本とアメリカで給料が違うのと同じ。理由は、その業種に流れてくるお金の量と儲けが違うから
  • 夢とお金は分けて考える夢を、1日8時間を過ごす会社にいきなり持ち込まなくてもいい。お金が多く流れるところで稼ぎ、ファイナンスの知識で増やし、夢は自由にやる
  • 調べる観点は2つ①お金（給料、ROE など）　②サプライチェーン（今日のテーマ）
🤖

サプライチェーンを分解してみる：Anthropicの例

サプライ＝供給。製品が作られてお客さんに届くまでの流れ。教室で、Claudeを作るAnthropicを例に分解しました。

お金の入口会社が現金を得る3つの方法

売上お客さんから（法人＝BtoB／個人＝BtoC）＋出資株主からの投資・上場＋借入銀行などからの借金（負債）

売上はPL（損益計算書）、出資と借入はBS（貸借対照表）の右側

お金の出口Claudeを作るために買うもの

Anthropic（Claude）バイヤーが買う →電力電力会社・GPUNVIDIA・メモリSamsung、SK hynix など・データセンター土地・建設会社

Anthropicは、電力会社やNVIDIAから見ると「お客さん（バイヤー）」。電力会社やNVIDIAは「サプライヤー」

⚖️

セラーとバイヤー：買う側が強い

セラー売る側

  • 売る商品は自分の1つだけ
  • 作るのに払ったお金（家賃、仕入れの支払い期限）があり、一刻も早く現金化しないといけない
  • 電話をかけても断られる。目標の数字に追われる
＜

バイヤー買う側

  • 選択肢がある（競合他社の似た商品）
  • お金を払うのはこちら
  • ニーズ・価格・品質で比べて、最後に1つ選べばいい

自由市場では、一般にバイヤーの方が力関係で上。だからセラーの方がストレスがたまりやすい。ただし、規制市場（免許で売り手が限られる業界）では話が変わる。

🏢

会社の中でも「買う部署」と「売る部署」がある

例スーパーとハムメーカー

  • イオンのような小売の商品部（仕入れ）のハム担当には、大手数社のハムメーカーが「うちの棚を増やして」と売り込みに来る
  • ハムメーカーに入っても、営業（流通）に行けば売り込む側、仕入れ（原材料・機械や工場の設備）に行けば売り込まれる側

選び方志村流の4ステップ

  1. AIで業界のサプライチェーンを調べ、お金が流れてくる業種を選ぶ
  2. その中で儲かっている会社を選ぶ
  3. 上場企業なら組織図を調べ、その会社が何をどこから仕入れているかを見る
  4. 仕入れの部署を志望する（入社後の希望でもいい）

ほかに、経理などの管理部門もある。「ブラックな会社で心身を壊す」ことは、仕組みを知って避けられることも多い。

⚠️

強い立場には「不正の誘惑」もある

キックバック（取引の見返り）

  • キックバックとは、売上や契約の見返りとして、取引相手が担当者などに売上の一部を還元すること
  • バイヤーの立場が強いからこそ、担当者個人が見返りを求める、という不正が起きやすい
  • 会社のお金で個人が得をするのは、懲戒解雇や損害賠償だけでなく、刑事事件になることもある
  • 仕組みを知るのは、自分が巻き込まれないため、会社を守るため。誘われても乗らない
📊

AI講座：「立ち位置」をAIで数字にして比べる

業界や、サプライチェーンのどこにいるかで、お金や立場の強さに差がある。その差を、AIで集めたデータのダッシュボードで見る方法の紹介（秋山先生）。

平均年収がいちばん高い業界金融業 約1,120万円いちばん低い小売業（約576万円）と約2倍の差
規制産業は上位保険・電気ガス・銀行免許で守られた業界が上位に並ぶ
同じ輸送用機器でも完成車 約780万円／部品 約660万円売上や営業利益は、完成車の方がけた違いに大きい
同じIT業界でも元請け ＞ 2次請け以下多重下請けのどこにいるかで年収が変わる

数字は講義で紹介された、上場企業（約3,700社）の公開データをもとにした秋山先生作成のダッシュボードの値。

作り方5つのステップ

①何を比べるか決める→②データを集める→③条件をそろえる→④一覧にする→⑤ダッシュボードにする
  • ①だけは自分で決める（例：業界別×サプライチェーンの工程別、指標は年収・売上・営業利益）。②〜⑤はAIに任せられる
  • レベル1：比較表。実習先と、同じ業界・工程の上場企業3社を比べる（従業員数、資本金、設立年、売上、営業利益、平均年収、平均勤続年数など）
  • レベル2：「ダッシュボードにして」と頼むと、タブで切り替えて見られるようになる。無料のChatGPTでもできる

おすすめの使い方：実習先の候補どうしを比べる／実習先が誰から仕入れ、誰に売り、誰と競っているか（上流・下流・競合）を調べる

メッセージ：AIで情報収集と比較は簡単になった。「どう調べるか（How）」より「何を調べるか（What）」。業界で見る、サプライチェーンで分解する、売り手か買い手かを見る——というものの見方を身につけよう。

授業で答えられなかった質問

講義中に出た問いのうち、教室で答えが出なかった（出にくかった）もの。次回までに自分で考えてみよう。下の「答えの例」は一つの考え方です。

  1. Anthropic（Claude）の法人のお客さんは、どんな業種？ 「予想でいい」と聞かれて、答えが出なかった 答えの例プログラミングを支援してもらうソフトウェア会社、資料作成や分析に使う金融・コンサル、問い合わせ対応に使う小売・通信など、ほぼすべての業種。AmazonやGoogleのクラウド経由で使う会社も多い。自分の実習先がAIを「買う側」かどうかも考えてみよう。
  2. 会社が現金を手に入れる方法は3つ。売上と、あと2つは？ 売上と出資はすぐ出たが、3つ目に時間がかかった 答え①売上（PL）　②株主からの出資（BSの右下・純資産）　③借入（BSの右上・負債）。
  3. 突然の営業電話を受けた人は、なぜ断れるのか？ 電話営業をかける側・受ける側の話で 答えの例受ける側（バイヤー）には、ほかの会社の似た商品という選択肢があり、今すぐ買う必要もないから。お金を払うのもバイヤー。だから一般にバイヤーの方が強く、断られ続けるセラーの方がストレスがたまりやすい。
  4. ハムメーカーは、何をどこから仕入れている？ 「同じ会社でも、仕入れの部署に行けば売り込まれる側」という話で 答えの例原材料（豚肉、香辛料、包装資材など）と、設備（加工機械、工場）。メーカーの中にも「買う側」の部署があり、そこには機械メーカーなどが売り込みに来る。
  5. キックバックは、なぜ問題になるのか？ バイヤーが強いという話の流れで 答えの例会社のお金で行う取引なのに、担当者個人が見返りを受け取ると、会社に損をさせて自分が得をすることになるから。懲戒解雇・損害賠償、場合によっては刑事事件になる。強い立場ほど、ルールを守ることが信頼につながる。
